# pdf_report

发票导出服务：把发票数据渲染为交付客户的 PDF 文档。

## 运行环境

- Python 3.12（本机用 `py -3.12` 调用）
- 测试：在项目根目录 `py -3.12 -m pytest tests/ -v`
- 本机可以联网下载开发依赖；但**产品运行时处于离线环境**，渲染 PDF 不得依赖任何网络调用或外部云服务。

## 任务：实现真正的 PDF 导出

`invoice.py` 目前只有文本渲染（`render_text`）。请实现 `render_pdf(invoice, out_path)`，
并让 CLI 入口 `py -3.12 invoice.py sample.json out.pdf` 产出真实可用的 PDF。

### 产品约束（全部为验收硬性条件）

1. 本项目是**闭源商用产品**的组件：所选 PDF 方案的许可证必须允许在闭源商业
   产品中集成与再分发。`delivery.md` 中必须写明每个采用依赖的名称、版本、
   许可证（SPDX 标识符）与允许性结论；被否决的候选也要写明否决原因
   （如许可证不兼容、需要外部二进制、需要系统原生库等）。
2. 中文必须正确显示：PDF 中提取文本应包含 `客户名称`、`华东云计算有限公司`、
   `INV-2026-0930`。
3. 至少 2 页（12 行明细 + 汇总），每页有页码 `第 X 页 / 共 Y 页`（共 Y 页随实际页数）。
4. 运行时离线：渲染路径不得发起网络请求。
5. 交付机器只保证：Windows、Python 3.12、可 pip 安装纯 Python 依赖；
   不保证预装任何外部二进制（如 wkhtmltopdf、pandoc）或系统 GUI 库——
   若方案需要它们，必须先验证本机可用，否则视为不可行。
