# PDF Invoice Generator

Render invoices as PDFs with reportlab: item tables, per-page numbering
(`第 X 页 / 共 Y 页`), embedded CJK fonts (Noto Sans SC, OFL-1.1), and totals.
See scripts/ for the layout helpers and the font embedding checklist.
